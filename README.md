# 관광e배움터 맞춤 강좌 추천

관광e배움터 강좌를 취업, 창업, 교육과정 설계 목적에 맞춰 탐색하는 정적 웹 서비스입니다.

**서비스:** [https://dd2-2.github.io/KTO_MIN/](https://dd2-2.github.io/KTO_MIN/)

## 주요 기능

- 취업 관심 직군과 세부 분야별 강좌 추천
- 창업 분야와 준비 과제별 강좌 추천
- 대학·관광 관련 학과별 강좌 추천
- 전체 강좌 검색 및 분류 필터
- 맞춤 추천 결과 엑셀 다운로드
- 데스크톱, 모바일 레이아웃 및 라이트·다크 테마

## 저장소 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 웹 서비스 전체 코드와 강좌 데이터 |
| `data/` | 원본 강좌 데이터와 학교·학과 정리 자료 |
| `downloads/` | 웹에서 제공하는 최종 엑셀 파일 |
| `docs/` | 작업 진행 기록 |
| `CLAUDE.md` | 후속 개발을 위한 프로젝트 인계 문서 |

## 로컬 실행

별도 빌드 과정 없이 저장소 루트에서 정적 서버를 실행합니다.

```powershell
python -m http.server 8791
```

브라우저에서 `http://127.0.0.1:8791/`에 접속합니다.
