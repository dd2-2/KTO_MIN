- 강좌 카드에는 순위 대신 `핵심 적합`, `높은 적합`, `연관 적합` 배지와 추천 근거를 표시

- 모바일에서 항목 선택 시 다음 단계로 자동 이동하고, 긴 추천 목록에는 우측 하단 `맨 위로` 버튼 제공
- 데스크톱 헤더에 `모바일` 버튼을 추가하고 390px 너비의 실제 조작 가능한 모바일 미리보기 제공
- 헤더의 전체·직무·공개·맞춤 강좌 건수 막대 제거

- 헤더 탭 순서를 `홈 / 취업 추천 / 창업 추천 / 기관용 / 전체 강좌`로 정리

- 취업·창업·기관용·전체 강좌 탭을 떠날 때 해당 화면의 선택·검색·필터 상태 초기화
- `⬇ 엑셀` 버튼을 `downloads` 폴더의 통합정리본 파일에 연결
- 엑셀 다운로드 버튼을 Excel 녹색으로 변경
